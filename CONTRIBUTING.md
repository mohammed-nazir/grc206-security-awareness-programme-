# Contributing

This is an individual academic repository. Changes should improve accuracy, evidence discipline, accessibility, formatting or programme usability without converting assumptions into facts.

## Workflow

1. Create a focused branch.
2. Explain the proposed change and its supporting evidence.
3. Update the Markdown report and, where required, the source Word document.
4. Check headings, tables, links, calculations, assumptions and references.
5. Open a pull request using the supplied template.

Do not commit real employee data, credentials, phishing target lists, live incident details or regulated customer information.
